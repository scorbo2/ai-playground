# Match 3 game refactoring

In this directory you will find a `Match3.html` file containing a "match 3" game implemented in html/css/javascript. 
Your task is to port this game to a Python application using the `pygame-ce` library and no other dependencies. 
The Python game should look as visually close to the original as possible: same colors, same dimensions for the 
game board and other UI elements, and the same or better animations. If you find bugs, deficiencies, or inefficient code
patterns in the source game, you are allowed and encouraged to improve and enhance them.

## Game rules

Port the game rules faithfully — all rules and scoring must behave identically to the original. 
The original documentation has been lost, so you will have to reverse engineer the rules of the game by examining the code.

## Sound

In the `sfx` subdirectory you will find several wav audio files and a `README.md` containing a mapping of audio 
files to their associated game events. The original game had no sound, but the Python port should include the 
indicated sound effects.
