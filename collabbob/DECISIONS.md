# Decisions

What follows is a record of decisions made by the implementing LLM
to handle anything that the spec didn't make explicit.

## Stage 1 — Walking skeleton + tooling

- The three config files use the full key set from the spec sketch, with
  medium values as the base and easy/hard tuned per the dev plan (easy:
  generous economy and better starting ship stats with lighter fuel usage;
  hard: smaller fares, faster fuel burn, pricier upgrades, weaker starting
  ship stats). `win_credits` is the same 1,000,000 in all three files.
- The ambiguous two-element fare lists (`economy.cargo_fare_per_unit`,
  `economy.passenger_fare_each`) are interpreted as the minimum and maximum
  per-unit fare rates; a mission fare = units * rolled rate * far-destination
  multiplier (far-destination bonus applied as a multiplier on the rolled
  fare).
- The schema is enforced with pydantic models (`extra="forbid"` so
  unrecognized keys are fatal, required fields so missing keys are fatal);
  numeric fields accept ints and floats as written in the config.
- The stage-1 main loop is a no-op skeleton: fixed 1/60 step with a bounded
  accumulator (limit 5/60), real dt ignored, window created before the loop
  starts. UI/scene/game logic is added in stages 2 onward.
- ESC quits the stage-1 window (no title screen exists at this stage).
- `resources/title_screen.png` is generated by
  `scripts/generate_title_screen.py` (dark 1024x768 gradient) so the title
  screen background exists at startup.
- The headless test harness runs under `SDL_VIDEODRIVER=dummy` and
  `SDL_AUDIODRIVER=dummy` via the root conftest.py, plus a
  `config_factory` fixture and `pump_events`/`advance` helpers in
  `src/harness.py`.
