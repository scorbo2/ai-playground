# LLM Battle 12

**Qwen 3.8 Flash Next vs Kimi K3.1 Pro**

## Challenge 1: Blender

Each model was tasked with taking a 2D isometric sprite and modelling it in Blender.

Results:

- Qwen: [qwen.blend](qwen.blend)
- Kimi: [kimi.blend](kimi.blend)

## Challenge 2: Godot

Each model was asked to take the objects they modelled in Blender, and bring them
into Godot with the aim of making a full playable game out of them.

Results:

- Qwen: [qwen](qwen/)
- Kimi: [kimi](kimi/)

## Bonus challenge: TTS engine implementation

Unrelated to the first two challenges, each model was asked to implement
support for a new TTS engine (KittenTTS). The code review of each model's
attempt is available here: [code_review.md](code_review.md)
